Vite provides development and build tooling underneath Astro. In this project, `astro.config.ts` connects the Tailwind Vite plugin and defines the `~` alias for imports from `src`.

I normally work through Astro's commands. Vite matters when I need to understand how an integration such as [Tailwind CSS](/tools/tailwind-css) connects to the build.
