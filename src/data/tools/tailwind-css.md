This site uses Tailwind CSS v4. Its utility classes describe layout and styling in the components, while shared color and font values live in the site's styling layer.

The configuration connects Tailwind through its [Vite](/tools/vite) plugin. I keep the reasoning behind the shared values in [Design tokens are the styling layer](../notes/design-tokens-are-the-styling-layer.md).
