# Archived Content

This directory contains content retained from the AstroWind starting point and the initial digital-garden experiment.

It is intentionally outside the loader bases configured in `src/content.config.ts`, so these files remain available in Git without being included in the live site build.

The original folder shape is preserved:

- `post/` contains the inherited AstroWind demo posts.
- `log/`, `notes/`, `articles/`, and `maps/` contain the first draft examples for the garden collections.

New public content belongs in the corresponding folders directly under `src/data/`.
