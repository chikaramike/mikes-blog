Mikes I/O is a YouTube channel that teaches technology from the ground up. Season 1 starts with a single question (where is this file?) and builds one skill per episode until you can learn to code with AI without losing the skill.

Each episode adds to one practice folder, `~/Developer/mikes-io-practice`. Read these in order:

1. Where your files actually live: files, folders, and paths.
2. Terminal, shell, CLI: your first ten minutes. Six commands, and what the window actually is.
3. Homebrew: install tools like a developer. The package manager.
4. VS Code is your workbench. Open a folder, not a file.
5. Markdown: plain text that outlives your apps. The format the rest of the season is written in.

Coming next: Git, GitHub and SSH keys, your first Python program, a plan for learning to code without scattering, learning with AI without losing the skill, and two episodes on choosing AI tools: how harnesses differ, and which model and plan to use in each.
